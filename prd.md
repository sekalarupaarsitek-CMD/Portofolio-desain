# 1. PRODUCT OVERVIEW

## 1.1 Product Background

SEKALARUPA STUDIO merupakan studio arsitektur yang berfokus pada perancangan hunian modern, fungsional, dan estetis. Studio ini mengembangkan desain berdasarkan kebutuhan klien, konteks lingkungan, dan nilai keindahan yang timeless.

SEKALARUPA STUDIO melayani kebutuhan desain untuk lingkungan pedesaan maupun perkotaan. Setiap perancangan mempertimbangkan karakter lokasi, fungsi ruang, serta kebutuhan pengguna.

Website ini akan menjadi platform digital resmi SEKALARUPA STUDIO untuk menampilkan portofolio, memperkenalkan layanan, membangun identitas brand, dan mempermudah calon klien mengajukan proyek.

Website juga harus memiliki sistem backend yang komprehensif. Administrator dapat mengelola seluruh konten, gambar, proyek, halaman, navigasi, dan tampilan website melalui dashboard visual.

Sistem backend menggunakan konsep hybrid visual editor yang menggabungkan kemudahan Canva dengan fleksibilitas website builder.

## 1.2 Brand Identity

**Brand Name:** SEKALARUPA STUDIO

**Brand Vision:**

"Create a Home that brings happiness."

**Filosofi Lokal:**

"Tatar Rupa Mawa Bagja."

Memiliki makna yang sama dengan visi dalam bahasa Inggris, yaitu menciptakan ruang dan hunian yang membawa kebahagiaan.

**Brand Philosophy:**

Sekalarupa Studio percaya bahwa setiap ruang memiliki cerita dan karakter tersendiri. Setiap desain lahir dari pemahaman terhadap kebutuhan klien, konteks lingkungan, fungsi ruang, serta nilai estetika yang bertahan dalam waktu.

**Core Brand Values:**

1. Contextual Design. Menghasilkan desain berdasarkan karakter lingkungan dan kebutuhan pengguna.
2. Functional Aesthetics. Menyeimbangkan fungsi, kenyamanan, dan keindahan.
3. Timeless Design. Mengutamakan desain yang relevan dan tidak mudah kehilangan karakter.
4. Human-Centered Approach. Menempatkan kebutuhan dan kebahagiaan pengguna sebagai bagian penting dari proses perancangan.

## 1.3 Product Vision

Membangun website profesional yang merepresentasikan karakter SEKALARUPA STUDIO sebagai studio arsitektur dan desain.

Website harus memberikan pengalaman visual yang kuat kepada pengunjung, memudahkan eksplorasi portofolio, serta menyediakan jalur komunikasi yang jelas untuk calon klien.

Backend harus memungkinkan administrator mengelola website secara mandiri tanpa memerlukan kemampuan pemrograman.

## 6.3 Inquiry Workflow

1. Pengunjung membuka halaman Start a Project.
2. Pengunjung mengisi formulir.
3. Website memvalidasi data.
4. Website menyusun ringkasan kebutuhan proyek.
5. Pengunjung menekan tombol Send via WhatsApp.
6. Website membuka WhatsApp dengan pesan yang telah disiapkan.
7. Pengunjung mengirimkan pesan secara langsung.

Contoh format pesan:

Hello SEKALARUPA STUDIO,

I would like to discuss a design project.

Name: [Name]
Service: [Service]
Project Type: [Project Type]
Location: [Location]
Budget: [Budget]

Project Description:
[Description]

I would like to discuss this project further.

Thank you.

Sediakan versi Bahasa Indonesia dengan isi setara.

**Important:** Website tidak boleh mengklaim pesan sudah terkirim sebelum pengguna menekan tombol Send di WhatsApp.

Untuk MVP, inquiry tidak disimpan sebagai lead di database. Website hanya menyiapkan pesan dan membuka WhatsApp.

Jika WhatsApp tidak tersedia di perangkat, browser harus tetap dapat membuka WhatsApp Web.

Visual Page Builder merupakan salah satu fitur utama produk.

Tujuannya adalah memberikan kemampuan editing website secara visual kepada administrator tanpa memerlukan pengetahuan HTML, CSS, atau JavaScript.

Pengalaman editing mengambil pendekatan Canva dan website builder modern.

Editor tidak menggunakan sistem full freeform yang membebaskan seluruh elemen berada pada koordinat sembarang.

Editor menggunakan kombinasi:

- Responsive grid.
- Flexible layout.
- Drag and drop.
- Element resizing.
- Layer management.
- Section-based layout.
- Visual properties panel.

Dengan demikian, administrator mendapatkan fleksibilitas desain dan website tetap responsif.

- Tidak mengizinkan perubahan visual yang merusak responsive behavior.
- Semua elemen menggunakan komponen yang tervalidasi.

Custom HTML dapat dipertimbangkan sebagai fitur lanjutan dengan pembatasan keamanan yang ketat.

JSON schema harus tervalidasi sebelum disimpan dan sebelum dirender.

# 12. SECURITY REQUIREMENTS

Keamanan merupakan bagian wajib dari pengembangan.

Persyaratan:

1. Admin authentication menggunakan Supabase Auth.
2. Tidak menyediakan public registration.
3. Admin login menggunakan email dan password.
4. Implementasikan secure session handling.
5. Gunakan Row Level Security (RLS) pada seluruh tabel yang membutuhkan perlindungan.
6. Public hanya dapat membaca data published.
7. Admin dapat mengelola data sesuai hak akses.
8. Validasi input di frontend dan backend.
9. Proteksi file upload berdasarkan format, ukuran, dan MIME type.
10. Lindungi seluruh halaman admin.
11. Terapkan rate limiting pada endpoint sensitif.
12. Gunakan HTTPS.
13. Jangan menyimpan credential di source code.
14. Jangan menampilkan error database yang berisi informasi sensitif.
15. Sediakan backup database secara berkala.

Untuk tahap awal hanya ada satu administrator.

Sistem tidak memerlukan fitur registrasi publik atau user management kompleks.
